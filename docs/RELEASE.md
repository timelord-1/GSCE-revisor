## Trilogy Revision 1.3.3

Adds an offline past-paper library for AQA Combined Science Trilogy (8464).

- 72 original PDFs: June 2023–2025, Biology/Chemistry/Physics, Paper 1/2, Foundation/Higher, question papers and matching mark schemes.
- Filter by subject, paper, tier and year. Open PDFs inside the app or save a copy.
- Published AQA file sizes and hashes are checked before packaging. Every PDF page must extract and render successfully in the release checks. `PAPER-VERIFICATION.json` records the result and any publisher-declared copyright omissions.
- Flashcards, personal cards, study plans and progress remain compatible.

Run `Trilogy-Revision-1.3.3-Windows-x64.exe` on Windows 10 or later (x64). Portable and unsigned. Verify against `SHA256SUMS.txt`.

Release checks include 25 unit/content tests, browser interactions and downloads, full PDF verification, and a packaged Windows smoke test that opens an included PDF. Publication only occurs after all checks pass.

AQA retains copyright in its original papers and mark schemes. This app is not affiliated with AQA.
