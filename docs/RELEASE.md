## Trilogy Revision 1.0.0

Offline GCSE revision for AQA Combined Science: Trilogy (8464).

- 486 original cards across 24 topics and six papers.
- Subject → paper → topic organisation, Higher/Foundation filtering and practical-method cards.
- Anki-inspired spaced repetition with Again/Hard/Good/Easy, due reviews, daily new-card limits and undo.
- Search, unscheduled practice and local progress with JSON backup/restore.

### Windows download

Download `Trilogy-Revision-1.0.0-Windows-x64.exe` and run it on Windows 10 or later (x64). No Node.js installation is required. The executable is portable and unsigned. The accompanying `SHA256SUMS.txt` records its checksum.

### Validation and limits

Scheduler/content checks and browser interaction tests pass on Linux. A Windows executable was built and its package structure checked; interactive execution on a Windows machine has not been verified here. This workflow produces the release artifact on Windows.

Answers are independently authored marking points, not official AQA mark schemes. Known separate-science topics are excluded. Direct checking against the full current official specification remains pending because AQA access was blocked in the development environment; see README and docs/COVERAGE.md. Use with course materials and past-paper practice.
